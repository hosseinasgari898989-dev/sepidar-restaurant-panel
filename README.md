# پنل رستوران سپیدار

این مخزن برای رابط پنل رستوران و فایل‌های پروژه‌ای است که در `sepidar-restaurant-panel.zip` ارائه شده‌اند.

## انتشار
پس از آماده‌شدن فایل‌های وب در شاخه `main`، در Settings → Pages می‌توان منبع انتشار را انتخاب کرد. رابط پنل در این نسخه برای اجرای نمایشی طراحی شده؛ اتصال واقعی ورود و مدیریت به API و D1 مستلزم استقرار هماهنگ بک‌اند Cloudflare است.

**مهم:** توکن‌ها و کلیدهای محرمانه را در این مخزن عمومی قرار ندهید.
